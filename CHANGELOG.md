# Changelog

## 0.2.0 — 2026-09-04

- Added OJS 3.5 Import/Export plugin entry point and per-journal settings.
- Added configurable Metafora API client foundation and safe connection test.
- Added publication metadata mapper for title, abstract, DOI, authors, affiliations, ORCID, issue, journal and references.
- Added publication galley/submission-file metadata mapping through OJS 3.5 repositories.
- Added publication selection UI and neutral JSON export for inspection.
- Added XSD validator, official schema registry and schema-validated XML export wrapper.
- Added documentation for official Metafora API/XSD sources and first-test installation.
- No API credentials are stored in the repository.

## 0.1.0 — 2026-09-04

- Initial OJS 3.5 Metafora import/export plugin skeleton.
