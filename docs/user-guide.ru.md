# Руководство пользователя Metafora Export Plugin 0.4.0.1

## Назначение

Плагин передаёт опубликованные статьи и выпуски из OJS 3.5 в ИС «Метафора» через API v2. Для статьи формируется JATS XML; при наличии публикационного PDF он может быть отправлен вместе с XML.

## Первичная настройка

1. В OJS откройте **Инструменты → Импорт/экспорт → Metafora Export Plugin**.
2. Укажите базовый URL API «Метафоры».
3. Введите API-ключ. Ключ хранится в настройках конкретного журнала и не должен попадать в Git или журналы диагностики.
4. Сохраните настройки и выполните проверку соединения.

## Отправка статей

1. Откройте вкладку статей.
2. Отметьте опубликованные статьи.
3. Нажмите кнопку отправки выбранных материалов.
4. Скачайте и сохраните отчёт обработки.
5. После обработки нажмите **Синхронизировать**, чтобы получить фактическое состояние публикации в «Метафоре».

## Отправка выпуска

На вкладке выпусков выберите выпуск и выполните отправку. Плагин обрабатывает опубликованные статьи выпуска и показывает проблемные материалы отдельно. Перед повторной отправкой синхронизируйте состояние выпуска.

## Состояния и действия

- **Не отправлено** — успешная отправка ещё не зафиксирована.
- **Отправляется** — операция выполняется.
- **Отправлено** — последняя локальная операция завершилась успешно.
- **Найдено в Метафоре** — публикация подтверждена удалённым API.
- **Не найдено в Метафоре** — удалённая публикация отсутствует.
- **Подписать / Снять подпись** — изменяет состояние подписи найденной публикации.
- **Восстановить** — повторно загружает публикацию, если файл известен, но публикация была удалена в «Метафоре».

Для действий подписи и восстановления сначала выполняйте синхронизацию. Подтверждайте действие только после проверки выбранной статьи.

## Обновление

1. Создайте резервную копию базы OJS и каталога плагина.
2. Скачайте ZIP нужного GitHub-релиза.
3. Замените каталог `plugins/importexport/metafora/`, не перенося старые `.bak`, `.before*` и другие временные файлы.
4. Откройте страницу плагина: необходимые таблицы состояния создаются или актуализируются автоматически.
5. Проверьте соединение и одну тестовую публикацию.

## Диагностика

Если операция завершилась ошибкой, раскройте детали в таблице и сохраните HTTP-код и текст сообщения. Не передавайте API-ключ. При откате восстанавливайте одновременно каталог плагина и резервную копию базы данных.
