# Источники интеграции ИС «Метафора»

Основные ресурсы:

- Общая документация: https://metafora.rcsi.science/documentation
- API Reference: https://metafora.rcsi.science/api_doc
- Интерфейс файлов: https://metafora.rcsi.science/files
- Интерфейс публикаций: https://metafora.rcsi.science/publications

XML-схемы:

- Journal: https://metafora.rcsi.science/xsd_files/journal3.xsd
- Science Space: https://metafora.rcsi.science/xsd_files/science_space_articles.xsd
- JATS 1.4 archive: https://metafora.rcsi.science/xsd_files/JATS-archive-oasis-article1-4.zip

## Политика секретов

API-токены и иные секреты не должны попадать в Git. Они задаются в настройках плагина на уровне журнала OJS и хранятся через механизм настроек плагина.
